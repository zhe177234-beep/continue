# 智学知识系统实施方案

毕设题目：基于知识图谱增强检索的个性化学习知识系统设计与实现。

## 阶段一：可运行的检索问答闭环

上传教材、解析分块、持久化知识库、混合检索、带出处问答。无模型时展示检索证据；无相关证据时拒答。支持本地模型与兼容 API，密钥由环境变量配置。

## 架构

Vue 3 前端、Spring Boot 业务后端、FastAPI AI 服务、PostgreSQL/pgvector。Docker Compose 部署，提供健康检查、示例资料、接口说明与测试。

## 后续阶段

知识图谱及检索路由、多模态文档解析、出题批改与错题、学习掌握度和学习路径、登录与知识库隔离、实验评测。

## 验收和论文实验

端到端验证上传到引用问答；检验无证据拒答、数据持久化和异常输入。比较关键词、向量、混合、图谱增强检索，记录 Recall@K、MRR、引用准确率及延迟。实验结果由真实运行产生；检索路由是否构成贡献需通过消融实验验证。

各模块按实际完成状态说明，骨架不视为完整交付。
