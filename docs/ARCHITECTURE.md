# 系统架构与实验设计

## 已实现的数据流

Vue 网页 → Nginx → Spring Boot 网关 → FastAPI → 账号业务 SQLite + 每个知识库独立 SQLite；可选 Ollama 提供向量与生成。开发模式 Vite 可直接代理 FastAPI。

Spring Boot 是 API 网关，不是已经完成 Java 迁移的业务主后端。网关校验方法、路径、大小与浏览器来源，转发 Cookie/Content-Type 并保留上游状态与 Set-Cookie。Python 层管理账号、知识库、学习记录、解析与检索。所有库访问都由服务端会话执行所有权检查。

## 存储

账号库：users、sessions、bases、history、quizzes、attempts。密码为带随机盐的 scrypt 哈希；原始会话令牌不入库，只保存 SHA256 摘要及到期时间。

知识库：documents、chunks、relations、embeddings。文档 ID 来自内容哈希，原文保存于 chunks；关系和向量依赖片段外键，文档删除时级联清理。向量保存模型名与 JSON 数组，仅查询当前模型名的索引。并发重复上传使用写事务，避免重复文档。

## 解析与检索

UTF-8 文本、文本型 PDF、DOCX/PPTX 文字，图片可选 Tesseract OCR。分块长 600 字、步长 500，PDF 不跨页，PPT 按幻灯片编号，DOCX 不保证分页。Office 先检查 ZIP 成员数与解压总大小。

BM25：k1=1.5、b=0.75。词项为英文词与中文二元字串。词频余弦提供第二种词汇基线；RRF 使用 1/(60+rank) 融合。关系增强给匹配实体的一跳关系证据加分 0.1。语义索引使用 Ollama /api/embed，精确余弦阈值 0.25，再与离线排名融合。阈值是待调参的工程基线，不是验证过的准确性保证。

模型回答受检索资料约束，引用须有编号且全部在证据范围内。编号校验只验证引用范围，无法证明事实一致性。模型失败或格式不合格时，降级到原文摘录并告知用户。资料不足时不给模型提供无证据回答机会。

## 练习与学习统计

显式三元组构建关系选择题，其他关系对象作为干扰项；相同主体/谓词的有效对象不作为干扰项。选项随机排序，每题首次提交计分。正确率用 Beta(1,1) 平滑：`(correct+1)/(attempts+2)`。复习顺序按该估计排序，对未练习知识点说明需要先阅读资料。不是经过验证的认知诊断模型。

## 论文实验方案

用有使用授权的多课程资料标注 100–200 个以上问题、相关证据和参考答案。按课程/文档划分开发集与测试集，问题改写不能跨集合泄漏；测试集不调参。

比较 BM25、词频、语义、混合与关系增强；保持解析、分块、语料与生成模型固定。报告 Recall@K、MRR、引用准确率、拒答正确率、事实一致性、延迟、资源占用及逐问题失败案例。消融关系增强、路由与分块策略；对结果给出置信区间。

当前 evaluate.py 只有 3 条人工问题，用于流程检查，不能据此声称创新或先进性。完整 GraphRAG、多跳与自动关系抽取需继续实现并另行测量实体关系准确率。

## 尚未实现与扩展

PostgreSQL/pgvector、业务向 Java 迁移、异步解析队列、多跳/社区 GraphRAG、自动知识关系抽取、图表与公式语义、多 Agent、自适应学习算法。当前这些是研究和工程扩展计划，不是完成状态。
